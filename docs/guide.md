# 使用說明

這是 Miller’s Anesthesia 第 10 版的繁體中文閱讀介面。87 章皆有繁中章名與主題索引，依九個臨床主題分組，並保留英文原文與原書章號。

## 快速搜尋

點選頂端「搜尋中文主題或英文關鍵字…」，輸入繁體中文醫學名詞、藥物名稱或章節內的關鍵字。電腦也可使用 **⌘ K** 或 **Ctrl K**。

- 搜尋範圍包含已匯入章節的標題與內文；不包含待匯入的章節。
- 中文不需空格，例如「呼吸道管理」；英文字母不分大小寫，例如「propofol」。
- 中文連續雙字可以找到較長句子中的詞彙。建議使用兩個字以上的關鍵字；單一中文字只會匹配獨立的單字詞。
- 中文可搜尋章名與人工整理的主題索引，例如「氣道管理」「心臟麻醉」「神經阻斷」或「丙泊酚」。英文可搜尋全文，例如「propofol」。未收錄的中文同義詞不會自動翻譯為英文。
- 多個詞以空格分隔時，結果需同時符合各個詞。
- 搜尋結果提供相關段落，開啟後可透過「章節導覽」切換段落。
- 搜尋不會換算劑量、推論適應症或自動產生醫療建議；請閱讀原段落中的條件與單位。

## 章節閱讀

有繁中臨床摘要的章節會在目錄標示「含臨床摘要」，內容依核心觀念、臨床處置、併發症與考點排列。點選摘要中的「原文第 N 頁」可跳到下方英文原文；頁碼為該章 PDF 頁序。摘要經自動來源檢查，仍需核對原文與現行臨床規範。尚無摘要的章節顯示英文原文。

在「章節目錄」可依章號、中文或英文標題、主題關鍵字篩選。九大分類涵蓋基礎醫學、藥理、監測、麻醉技術、疼痛、專科、小兒、重症與研究；章號沿用原書。「上一章」「下一章」依原書章號排列。

閱讀時，桌面右側顯示「本頁大綱」；手機右下方有「章節導覽」，段落名稱保留原文。向下捲動後會出現「快速回到頂部」。寬表格可左右滑動；程式碼會自動折行。

點選導覽列的外觀切換鈕，可在淺色與深色模式之間切換。手機的外觀切換位於右上角選單內。

## 離線閱讀

1. 首次使用請保持網路連線，開啟正式版網站。完整離線內容包含全文、圖表與原頁影像，建議先使用 Wi-Fi，並預留約 500 MiB 的裝置空間。
2. 等待左下角顯示 **「已可離線閱讀」**。大型章節或圖檔可能需要較久時間。
3. 完成後，所有已匯入章節、搜尋索引與本地附件皆可離線讀取，不必逐章開啟。
4. 關閉網路後，狀態會變為「離線閱讀中」。可開啟尚未讀過的章節並搜尋。

只有安裝圖示不代表快取已完成。瀏覽器可能因儲存空間不足、手動清除網站資料或長期未使用而移除快取；重新連線並確認狀態後即可再次離線使用。站外連結不包含在離線內容中。

::: tip 有新版本時
網站會提示「手冊有新版本」。選擇「立即更新」會重新載入頁面，套用新的章節與搜尋內容；也可以稍後再更新。
:::

## 安裝到主畫面

### iPhone 與 iPad：Safari

1. 使用 **Safari** 開啟網站的 **HTTPS 網址**。
2. 等待「已可離線閱讀」。
3. 點選 Safari 的「分享」按鈕；部分版本需先開啟「⋯」選單。
4. 選擇「加入主畫面」。若沒有顯示，可在分享選單中向下尋找或編輯動作。
5. 確認名稱「米勒麻醉學」，若有「以網頁 App 開啟」選項請啟用，再點選「加入」。
6. 從主畫面的圖示開啟一次，確認離線狀態；關閉網路後重新開啟並切換章節。

Safari 不支援網站直接跳出 Android 式安裝視窗，請使用分享選單。

### Android：Chrome

1. 使用 **Chrome** 開啟網站的 **HTTPS 網址**。
2. 等待「已可離線閱讀」。
3. 若網站出現「安裝手冊」，點選並確認；也可從 Chrome「⋮」選單選擇「安裝應用程式」或「加到主畫面」。文字會依版本而異。
4. 從主畫面開啟，確認以獨立視窗顯示。
5. 關閉網路，重新開啟一個未讀過的章節並搜尋。

臨床使用前，請核對原文、劑量單位、適用族群與院內最新規範。
