# 手機安裝 App

將米勒麻醉學以 **PWA 網頁 App** 加入主畫面，即可用獨立視窗開啟，閱讀 87 章與搜尋中英關鍵字。

[閱讀章節](/chapters/) · [iPhone／iPad 安裝步驟](#iphone) · [Android 安裝步驟](#android)

## 安裝前準備

1. 使用手機開啟本網站的 **HTTPS 網址**。若從 LINE、Facebook 或其他 App 開啟，請改用 Safari 或 Chrome。
2. 本站目前為私人網站；若出現登入畫面，請登入網站擁有者的 ChatGPT 帳號。
3. 連接 Wi-Fi，並預留至少約 **500 MiB** 的儲存空間，供全文、圖表與原頁影像離線使用。
4. 等待畫面左下角由「正在準備離線內容…」變成 **「已可離線閱讀」**。第一次下載需要時間，請保持頁面開啟。

## iPhone／iPad：使用 Safari {#iphone}

1. 在 **Safari** 開啟本網站，完成登入。
2. 點選 **分享** 按鈕（方框向上箭頭）；部分版本需先開啟「⋯」選單。
3. 向下捲動，選擇 **加入主畫面**。若沒有此項目，可查看分享選單的「編輯動作」。
4. 名稱使用 **米勒麻醉學**。若有「以網頁 App 開啟」選項，請開啟。
5. 點選 **加入**，回到主畫面開啟「米勒麻醉學」圖示。
6. 若 App 內再次出現登入畫面，請使用同一個 ChatGPT 帳號登入；保持連線，確認 App 內也顯示「已可離線閱讀」。

Safari 與主畫面 App 的儲存狀態可能不同，請在安裝後開啟的 App 內完成一次離線確認。

## Android：使用 Chrome {#android}

1. 在 **Chrome** 開啟本網站，完成登入。
2. 若左下角出現 **安裝手冊**，點選並依提示安裝。
3. 也可點選 Chrome 右上角 **⋮** → **安裝應用程式** 或 **加到主畫面**。不同版本的選單名稱可能不同。
4. 確認名稱 **米勒麻醉學**，按下 **安裝／加入**。
5. 從主畫面開啟 App，確認畫面左下角顯示 **已可離線閱讀**。

若選單暫時沒有安裝項目，請確認網址使用 HTTPS、不是無痕模式，並更新 Chrome 後重新整理。

## 確認可離線閱讀 {#offline}

1. 開啟安裝好的 App，等待「已可離線閱讀」。
2. 開啟飛航模式，並確認 Wi-Fi 也已關閉。
3. 開啟尚未讀過的章節，例如 **第 87 章：醫學文獻判讀**，再重新整理。
4. 搜尋 **氣道管理** 或 **propofol**，確認有結果。
5. 開啟含圖片的章節，確認圖表及「原始表格與符號」中的原頁影像可以顯示。

若顯示「尚未完成離線快取」，請恢復網路並等待完成。瀏覽器清除網站資料、裝置空間不足或重新安裝後，需要重新下載。

## 更新與重新安裝

網站更新後會顯示 **手冊有新版本**。請在有網路時按 **立即更新**，並再次確認離線狀態。

若已安裝舊網站的圖示，請先安裝並確認這個新網站可正常開啟，再刪除舊圖示。新舊網址的離線資料各自儲存，無法共用。
